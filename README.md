# Loop Dots

Widget Android minimalista e transparente para acompanhar um hábito diariamente.

- 28/29/30/31 bolinhas conforme o mês real.
- Toque em uma bolinha para marcar/desmarcar o dia.
- Dias marcados ficam vermelhos.
- Contador acumulado preserva os dias concluídos de todos os meses.
- GitHub Actions gera o APK de debug.
